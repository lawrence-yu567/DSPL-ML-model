This is an extension to the modelling_dspl project. Theoretically, if we are able to simulate a vast amount of mock dspl systems, we are unshackled from one of current gravitational lensing research's greatest drawback,the lack of observed and well-studies systems. By simulating the physical properties of 10s of thousands of dspls, we enter the realm of big data and machine learning. Because of the amount of data possible from this approach, we we able to train ML models to predict the possible cosmological constraints a dspl can have.

Cosmologic constraint derived from dspl is a proven method to improve the precision on cosmological constants (Collett & Auger, 2014). We wish to indentify the pattern in dspl configurations and their constraining abilities.

Current model is a proof of concept
